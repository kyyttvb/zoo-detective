2. Present Simple Rules

Verb + -s / -es

With he / she / it (one animal), add -s or -es to the verb.

A hedgehog sleeps during the day.
to be + Adverb

Put usually / never AFTER am / is / are.

A hippo is never small.
Adverb + Verb

Put usually / never BEFORE the main verb.

An armadillo usually lives in dry places.
doesn't + Base Verb

With he / she / it, use doesn't + base verb (no -s).

A snake doesn't have arms.
